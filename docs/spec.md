# 广州办公软件 - Electron + Vue + Vite 实现方案

> **目标:** 将原PySide6实现的"四方阁"桌面应用转换为Electron+Vue+Vite架构，保持相同功能但使用清爽的纯白+职业蓝UI

**架构:** Electron主进程 + Vue 3前端 + TypeScript + Vite构建

**技术栈:**
- 前端框架: Vue 3 + TypeScript + Vite
- UI方案: 自定义CSS组件 + CSS变量主题
- Excel处理: xlsx库 (前端直接处理)
- 图片处理: canvas + rembg (Node.js子进程调用Python)
- Electron: 用于原生文件对话框、系统集成

**UI配色方案:**
- 主色: #1976D2 (职业蓝)
- 主色悬停: #1565C0
- 背景: #FFFFFF (纯白)
- 侧边栏背景: #F8FAFC (淡灰白)
- 文字主色: #1E293B (深灰)
- 文字次色: #64748B (中灰)
- 边框: #E2E8F0 (浅灰)
- 成功: #22C55E
- 错误: #EF4444

## 功能模块

| 模块 | 功能 |
|------|------|
| 销售合同转装箱单 | 销售合同(PI)转换为装箱单(PL)+对账单 |
| 销售合同转生产单 | 销售合同转换为生产单 |
| 图片背景移除 | 批量移除图片背景 (调用Python rembg) |
| 产品图片生成 | 图片拼接到模板生成产品展示图 |
| 帮助 | 帮助文档 |
